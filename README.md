# 🏡 Real Estate Price Prediction in Bulgaria

A Machine Learning project focused on predicting real estate prices in Bulgaria using various property features such as location, size, and other relevant attributes.

---

## 📌 Project Overview

The goal of this project is to build a predictive model that estimates property prices based on historical data. This can be useful for:

- 🏠 Buyers – to estimate fair market prices  
- 🏢 Investors – to identify profitable opportunities  
- 📊 Analysts – to understand market trends  

The project follows a typical ML pipeline including data preprocessing, exploratory data analysis (EDA), feature engineering, and model training.

---

## ⚙️ Technologies Used

- Python 🐍  
- Pandas & NumPy (data processing)  
- Matplotlib / Seaborn (data visualization)  
- Scikit-learn (machine learning models)  
- Jupyter Notebook  

---

## 📊 Dataset

The dataset contains real estate information such as:

- 📍 Location  
- 📐 Property size (sq.m)  
- 🛏️ Number of rooms  
- 🏗️ Property type / condition  
- 💰 Price (target variable)  

> Data is preprocessed to handle missing values, outliers, and categorical variables.

---

## 🔍 Exploratory Data Analysis (EDA)

- Distribution of prices  
- Correlation between features  
- Impact of location on price  
- Outlier detection  

---

## 🧠 Model

The project uses regression techniques such as:

- Linear Regression  
- (Optional) Random Forest / Gradient Boosting  

### Steps:
1. Data cleaning  
2. Feature engineering  
3. Train-test split  
4. Model training  
5. Evaluation  

---

## 📈 Model Evaluation

Performance is evaluated using:

- R² Score  
- Mean Squared Error (MSE)  
- Root Mean Squared Error (RMSE)
